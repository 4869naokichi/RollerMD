# 制御処理の実装

[README に戻る](../README.md)

## 制御ループ

TIM6 更新割り込み（`TIM6_DAC1_IRQHandler`）から `controller()` を実行します。コード中の制御周期は `T_ctrl = 0.001f`（**1 ms / 1 kHz**）です。

処理の概要：

1. TIM3 のエンコーダカウント増分を取得し、カウンタをゼロに戻す。
2. エンコーダカウントから角速度 `omega` [rad/s] を計算する。
3. 指令値 `ref` と角速度との差を求め、PI 制御量を計算する。
4. ローパスフィルタとモータ逆モデルから外乱推定値 `d_hat` を計算する。
5. PI 制御量に `d_hat` を加え、`setMotor()` で PWM 比較値を更新する。

角速度演算で用いている設定値：

| 項目 | 値 |
| --- | --- |
| `T_ctrl` | 0.001 s |
| `PPR` | 2048 |
| `CPR` | `PPR * 4 = 8192` |
| 回転方向の符号 | `-LL_TIM_GetCounter(TIM3)` を使用 |

角速度は次式に対応します。

~~~text
omega = (-encoder_count) / T_ctrl / CPR * (2 * pi)
~~~

エンコーダの仕様や配線方向により、`PPR` や符号を調整してください。

## PI 制御

制御器は PID 形式で記述されていますが、現在の `K_d` が `0.0f` のため **PI 制御**です。積分は台形則で更新します。

現在有効な定数（コード内のコメントでは「下のローラー」）：

| 定数 | 値 |
| --- | ---: |
| `K_p` | 0.570265010581587 |
| `K_i` | 6.00085498191391 |
| `K_d` | 0 |

「上のローラー」用の別ゲインはコード内にコメントアウトされています。ゲインは対象のモータや機構に合わせて調整してください。

## 外乱推定・補償

コードでは次の計算を行います。

~~~text
d_hat = LPF(output_pre) - FGinv(omega)
output = PI_output + d_hat
~~~

- `LPF()`：カットオフ角周波数 `omega_c = 100 rad/s` の一次ローパスフィルタ
- `FGinv()`：ローパスフィルタを含むモータ逆モデル
- `output_pre`：前周期に計算した操作量（`setMotor()` による制限前）
- `setMotor()`：PWM 比較値の範囲を `-950` ～ `950` に制限

現在有効なモータモデル定数（「下」）：

| 定数 | 値 |
| --- | ---: |
| `K` | 5.240304638093135 |
| `T` | 0.10560630397470239 |
| `omega_c` | 100 rad/s |

`main.c` にある別の `PID()` 関数は、現在の `controller()` からは呼び出されていません。

## ゼロ指令・リセット時の挙動

`ref` が `+INFINITY` またはほぼゼロ（`fabsf(ref) < 0.001f`）のとき、PI 積分値と PI 出力のリセット処理に入ります。ただし、

~~~text
d_hat = LPF(output_pre) - FGinv(omega)
output += d_hat
~~~

がその後に実行されるため、**最終出力が必ず 0 になるわけではありません**。安全停止として利用しないでください。

また、積分器のアンチワインドアップ、通信タイムアウト停止、監視タイマに基づく安全停止は実装されていません。再利用時は必要な保護機能を追加し、機構に適したパラメータで検証してください。
