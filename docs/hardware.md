# 対象ハードウェアとピン配置

[README に戻る](../README.md)

## 対象

- マイコン：**STM32F303K8T6**（LQFP32）
- STM32CubeMX の対象ボード：**NUCLEO-F303K8**
- 設定クロック：SYSCLK 64 MHz
- ペリフェラル：TIM1 / TIM3 / TIM6 / TIM7 / USART2

## ピン割り当て

| MCU ピン | ラベル | ペリフェラル | 用途 |
| --- | --- | --- | --- |
| PA8 | `PWM1H` | TIM1_CH1 | PWM 出力 1 |
| PA7 | `PWM1L` | TIM1_CH1N | PWM 出力 1 の相補信号 |
| PA9 | `PWM2H` | TIM1_CH2 | PWM 出力 2 |
| PB0 | `PWM2L` | TIM1_CH2N | PWM 出力 2 の相補信号 |
| PA6 | `ENCB` | TIM3_CH1 | インクリメンタルエンコーダ入力 |
| PA4 | `ENCA` | TIM3_CH2 | インクリメンタルエンコーダ入力 |
| PA2 | `VCP_TX` | USART2_TX | UART 送信 |
| PA15 | `VCP_RX` | USART2_RX | UART 受信 |
| PA13 | `SWDIO` | SWDIO | デバッグ |
| PA14 | `SWCLK` | SWCLK | デバッグ |
| PF0 | `MCO` | RCC_OSC_IN | クロック関連設定 |

信号ラベルはソースコード／`.ioc` のものです。NUCLEO のコネクタ端子や VCP 接続の利用可否については、実際のボード配線・ジャンパ設定を確認してください。

## タイマ・通信周辺機能

| 機能 | 設定・用途 |
| --- | --- |
| TIM1 | PWM 出力（CH1/CH1N、CH2/CH2N）、ARR = 999、Prescaler = 0 |
| TIM3 | エンコーダインタフェース（4 逓倍）、16 bit カウンタ |
| TIM6 | 制御ループ起動用更新割り込み（Prescaler = 63、ARR = 999、約 1 ms） |
| TIM7 | 初期化してカウンタを開始（主要な制御演算では直接使用していない） |
| USART2 | 115200 bps、8N1、送受信 |

`setMotor()` は正の操作量を TIM1 CH1、負の操作量を TIM1 CH2 の比較値へ与え、反対側の比較値を 0 にします。操作量は `-950` ～ `950` に制限されます。TIM1 の相補出力やデッドタイムの詳細は `tim.c` / `.ioc` を確認してください。

## 実機接続前の確認項目

1. 接続先モータドライバの入力論理・PWM 極性・相補 PWM の要否を回路図と照合する。
2. MCU、エンコーダ、モータドライバの電圧レベル、電源投入順序、GND を確認する。
3. エンコーダ A/B と回転方向の符号を低速で検証する。
4. モータが予期せず回転しても停止できる独立した手段を用意する。
5. 実機の PPR が `main.c` の `2048` と一致するか確認する。
6. 駆動前に PWM 周波数・波形・デッドタイムを計測する。
